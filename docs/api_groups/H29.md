# H29 Group

This is the group of HTTP APIs between the **Partner Portal** and [Partner's Knowledge Update Service](../services/partner/S12_Partner_Knowledge_Update_Service.md).

This API consists of 1 API.

## Regarding HTTP API(s)
Endpoints denoted with "AUTH" means that it must be authenticated using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H29

**Direction:** Core Portal(Frontend) → S12

This API is based on HTTP (RESTful).

The API has 3 endpoints serving 3 main tasks:
1.  Create new data update draft
2.  Delete draft update
3.  Submit update to Telcenter Core for validation

### H29 Endpoint: `POST AUTH /api/v1/updates/create`

This endpoint is called by Partner Portal to create a new knowledge update draft. Note that this request does not contain the data itself. The backend will fetch the update data (df) from the Local Knowledge DB via A33, convert it to JSON format, and store it in SeaweedFS. The returned draft object will contain the reference to this SeaweedFS file.


Request body format:

```json
{
  "source": "Viettel",
  "update_name": "Cập nhật gói cước Q4 2025",
  "update_type": "new_entries",
  "priority": "normal",
  "notes": "Gói cước khuyến mãi quý 4 năm 2025"
}
```

Update types:
- `"new_entries"` - New service packages
- `"modifications"` - Updates to existing packages
- `"corrections"` - Corrections to previously submitted data

Priority levels:
- `"high"` - Urgent update
- `"normal"` - Standard priority
- `"low"` - Non-urgent

Response format (HTTP 201 Created):

```json
{
  "status": "success",
  "update_id": "draft_upd_1234",
  "update_status": "draft",
  "message": "Đã tạo bản cập nhật draft thành công",
  "update": {
    "update_id": "draft_upd_1234",
    "update_name": "Cập nhật gói cước Q4 2025",
    "source": "Viettel",
    "update_type": "new_entries",
    "priority": "normal",
    "entry_count": 2,
    "seaweed_file_id": "3,01637037d6",
    "created_at": "2025-12-08T10:30:00Z",
    "created_by": "employee_456",
    "status": "draft"
  }
}
```

Error responses:

**HTTP 400 Bad Request**
```json
{
  "status": "error",
  "error_code": "INVALID_INPUT",
  "message": "Dữ liệu đầu vào không hợp lệ",
}
```

**HTTP 401 Unauthorized**
```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Token xác thực không hợp lệ hoặc đã hết hạn"
}
```

**HTTP 403 Forbidden**
```json
{
  "status": "error",
  "error_code": "FORBIDDEN",
  "message": "Người dùng không có quyền tạo bản cập nhật"
}
```

### H29 Endpoint: `DELETE AUTH /api/v1/updates/{update_id}`

This endpoint is called by Partner Portal to delete a knowledge update that is in draft status.


URL Parameters:
- `update_id`: The ID of the update to delete (e.g., `draft_upd_1234`)

Response format (HTTP 200 OK):

```json
{
  "status": "success",
  "message": "Đã xóa bản cập nhật draft thành công",
  "deleted_update": {
    "update_id": "draft_upd_1234",
    "update_name": "Cập nhật gói cước Q4 2025",
    "status": "draft",
    "entry_count": 2,
    "deleted_at": "2025-12-08T11:00:00Z",
    "deleted_by": "employee_456"
  }
}
```

Error responses:

**HTTP 400 Bad Request** - Cannot delete
```json
{
  "status": "error",
  "error_code": "CANNOT_DELETE",
  "message": "Không thể xóa bản cập nhật",
  "details": "Chỉ có thể xóa bản cập nhật ở trạng thái draft",
  "current_status": "submitted"
}
```

**HTTP 404 Not Found**
```json
{
  "status": "error",
  "error_code": "NOT_FOUND",
  "message": "Không tìm thấy bản cập nhật với ID này"
}
```

**HTTP 401 Unauthorized**
```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Token xác thực không hợp lệ hoặc đã hết hạn"
}
```

**HTTP 403 Forbidden**
```json
{
  "status": "error",
  "error_code": "FORBIDDEN",
  "message": "Người dùng không có quyền xóa bản cập nhật này"
}
```

### H29 Endpoint: `POST AUTH /api/v1/updates/{update_id}/submit`

This endpoint is called by Partner Portal to submit a knowledge update draft to Telcenter Core for validation.


URL Parameters:
- `update_id`: The ID of the update to submit (e.g., `draft_upd_1234`)

Request body format (optional):

```json
{
  "submission_notes": "Vui lòng xem xét và phê duyệt",
  "expected_validation_time": "urgent"
}
```


## Configuration

Base URL should be configurable via `.env`:
- `PARTNER_KNOWLEDGE_UPDATE_SERVICE_URL` (e.g., `http://localhost:7012`)

## Notes

- All requests require JWT authentication with partner employee credentials
- Rate limiting: 30 submissions per hour per user
- Maximum entries per update: 1000
- Validation typically takes 30-120 seconds (includes Core communication over Internet)
- Draft updates are stored locally until submitted
- Only draft updates can be deleted
- Once submitted, updates cannot be modified or deleted
- Failed submissions due to network issues can be retried by resubmitting
- Rejected updates (validation failed) should be fixed and created as new drafts
- All submissions are logged for audit purposes
- CORS enabled for Partner Portal domain
- Partner Portal should poll the status endpoint every 5-10 seconds during validation
- Status is retained for 30 days after completion
